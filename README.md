# Mandalingo：霧隱鎮

一款以情境探索學習華語的武俠冒險遊戲。你從南門庭院出發，觀察人物、物品與事件，穿過城門走進霧隱鎮；語言的意思由世界慢慢說明，而不是由介面直接給答案。

**[遊玩瀏覽器版本](https://leo57991.github.io/mandalingo-adventure/)**

![霧隱鎮南門與街道的暮色概念美術](assets/mandalingo-key-art-v2.png)

## 現在可以玩到什麼

- 在即時 3D 南門庭院與相連的城鎮中自由探索，不需要切換關卡；城鎮有商鋪、居民、橋、井與可互動物件。
- 從守門人與旅人的動作、對話和環境線索，推測他們的意思與需要。觀察、取水、遞水和開門會改變眼前的世界。
- 遇到中文後，在筆記本保留自己的猜測及觀察記錄。遊戲不立即顯示翻譯、拼音或正誤判定。
- 進度保存在此瀏覽器的 `localStorage`。標題畫面可重播開場，原有筆記與進度會保留。

目前的瀏覽器版本是一段可玩的垂直切片，仍在持續製作；美術與內容可能調整。

## 操作

| 動作 | 操作 |
| --- | --- |
| 移動 | `WASD` 或方向鍵 |
| 奔跑 | 按住 `Shift` |
| 對話／觀察／繼續 | `E` |
| 筆記本 | `N` |
| 暫停／關閉介面 | `Esc` |

筆記內容可用滑鼠編輯。遊戲以桌面瀏覽器及鍵盤操作為主要體驗。

## 本機開發

需要 Node.js。瀏覽器原型使用原生 JavaScript、Three.js 模組、HTML、CSS 與 Web Audio API；不需要打包器。

```bash
npm run dev
```

開啟 `http://127.0.0.1:4173`。執行檢查：

```bash
npm run check
```

`src/` 是目前瀏覽器遊戲的邏輯與 3D 場景，`assets/` 是介面與參考圖像，`godot/` 是可編輯的 Godot 4 物件化切片，`godot-web/` 是既有的 Web 匯出檔。`desktop/` 與 `npm run desktop:build` 用於 Electron 桌面包裝。

## 視覺方向

霧隱鎮以水墨暮色、青玉、舊銅與暖金燈火為共同語言。門、街道、燈與人物都應幫助玩家看懂場景中的行為與語境；裝飾不應遮住可互動的人與物。美術為原創設計，不直接複製其他作品。
