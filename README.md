# Mandalingo：霧隱鎮

Mandalingo 是一款面向華語零基礎學習者的 PC 探索遊戲。玩家進入古風修仙城鎮，透過人物動作、場景物品與反覆出現的語境，自行推測原本無法理解的中文。

**[Play the current browser prototype](https://leo57991.github.io/mandalingo-adventure/)**

![Mandalingo key art](assets/mandalingo-key-art.png)

## 核心設計

這不是傳統的單字測驗遊戲。遊戲不顯示拼音、不考聲調，也不會在玩家輸入猜測後立即判定正誤。

- 以可理解輸入與情境線索推測詞義
- 使用 WASD 探索城鎮，與 NPC、招牌及場景物品互動
- 遇見的詞自動記入筆記本
- 玩家用英文寫下可隨時修改的假設
- 記錄詞語出現次數、所有地區及最後出現地點
- 由玩家自行標記「已理解」，再轉化為使用自己猜測的 flashcards
- 使用遇過的詞組合言靈、解決事件並改變城鎮狀態

## 目前垂直切片

目前版本是「霧隱鎮」的零相依瀏覽器原型，用來驗證 Godot 版本之前的核心學習迴圈：

1. 在一張相連的俯視地圖上探索南門、長街、茶坊、雲水橋與問仙臺，鏡頭會平滑跟隨角色。
2. 從守門人、茶攤老闆、挑水人、藥師與場景物品取得情境線索。
3. 讓 14 個初始詞彙在不同語境中反覆出現。
4. 在筆記本中建立、修改並自行確認英文猜測。
5. 從井與人物動作推測一名弟子的需要，再以遇過的詞組成言靈完成事件。

所有進度保存在瀏覽器 `localStorage`，重新整理後仍會保留。

## 操作

| 動作 | 鍵盤 | 觸控裝置 |
| --- | --- | --- |
| 移動 | `WASD` / 方向鍵 | 左側虛擬搖桿 |
| 對話／觀察／繼續 | `E` | 右側 Interact |
| 開啟筆記本 | `N` | HUD 的 Notebook |
| 關閉介面 | `Esc` 或介面按鈕 | 介面按鈕 |

## 本機執行

```bash
npm run dev
```

開啟 `http://127.0.0.1:4173`。

```bash
npm run check
```

測試涵蓋詞語出現紀錄、玩家猜測、自行確認、flashcards 與言靈事件條件。

## 技術與後續方向

目前原型使用 Vanilla JavaScript、HTML Canvas、CSS、Web Audio API 和 GitHub Pages，並以大型世界座標、跟隨鏡頭與小地圖呈現俯視探索。正式製作仍以 Godot 及 2D／偽 2.5D PC 遊戲為目標；這個版本先驗證敘事、輸入設計、筆記資料模型與事件節奏。

視覺方向採用原創古風修仙與紙本質感，不直接複製任何參考作品的角色、場景或介面素材。
